# SkillSync Frontend

React frontend for SkillSync, built with Vite.

## Tech stack

- React 18
- Vite 5

## Prerequisites

- Node.js **18+** (recommended)
- npm **9+**

## Install

From `skillsync-frontend/`:

```bash
npm install
```

## Run locally (dev)

```bash
npm run dev
```

- Dev server: `http://localhost:3000`
- API proxy: requests to `/api/*` are forwarded to `http://localhost:8080` (see `vite.config.js`)

## Build (production)

```bash
npm run build
```

The output is generated by Vite (typically under `dist/`).

## Preview production build

```bash
npm run preview
```

## Troubleshooting

- **API calls failing in dev**: ensure the backend is running on `http://localhost:8080` and requests are using the `/api` prefix (so Vite proxy can forward them).
- **Port 3000 already in use**: change `server.port` in `vite.config.js` or stop the process using port 3000.
