# SkillSync 🚀

SkillSync is a full-stack Java application that tracks developer skills, analyzes coding activity, and generates personalized learning roadmaps.

## 🧠 Problem Statement
Developers often struggle to:
- Track real skill progress
- Decide what to learn next
- Measure consistency and improvement

SkillSync solves this by combining DSA tracking, skill evaluation, and GitHub activity analysis.

## ✨ Features
- User authentication with JWT
- Skill & DSA progress tracking
- Rule-based learning recommendations
- Weekly roadmap generator
- GitHub profile analysis

## 🛠 Tech Stack
**Backend**
- Java 17
- Spring Boot
- Spring Security
- Hibernate / JPA
- MySQL

**Frontend**
- React / JSP + Bootstrap

## 🏗 System Architecture
SkillSync follows a layered architecture with modular separation.

Modules:
- Authentication & Authorization
- Skill & DSA Tracking
- Recommendation Engine
- GitHub Integration
